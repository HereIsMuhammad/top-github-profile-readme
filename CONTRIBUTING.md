# Contributing to Top Github Profile READMEs

Thanks for wanting to add your profile! Here's exactly how to do it.

## Steps

1. **Fork** this repository to your own GitHub account.

2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/your-username/top-profile-readme.git
   cd top-profile-readme
   ```

3. **Open `README.md`** and find the table under "Browse the List".

4. **Add a new row**, following this exact format:
   ```markdown
   | Your Name | [your-username](https://github.com/your-username) | [README](https://github.com/your-username/your-username/blob/main/README.md) |
   ```
   Replace `your-username` with your actual GitHub username, and make sure
   the README link points to the real source file of your profile README.

5. **Keep the table alphabetically sorted** by first name, insert your row
   in the right position rather than always adding it at the bottom.

6. **Commit and push**:
   ```bash
   git add README.md
   git commit -m "Add [Your Name] to the list"
   git push origin main
   ```

7. **Open a Pull Request** back to this repository, with a short
   description (just "Adding my profile" is fine).

## What Gets Accepted

- The README must actually be yours, don't add someone else's profile
  without asking them first
- It should be publicly visible (not a private repo)
- No spam, offensive content, or unrelated links

## What Doesn't Get Accepted

- Duplicate entries
- Broken links
- PRs that touch anything outside your own table row
- Profiles that are empty or clearly just placeholders

## Questions?

Open an issue if anything here is unclear, happy to help.
