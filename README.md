# Top GitHub Profile READMEs 🌟

A community-curated collection of standout GitHub profile READMEs.

Your GitHub profile README is often the first thing people see when they
click your username, before your pinned repos, before your contribution
graph. This project collects genuinely well-made examples in one place, so
anyone looking for inspiration (or just curious what's possible) has
somewhere to browse.

If you've put effort into your profile README and you're proud of it, open
a PR and add yourself to the list below, or reach out and I'll add it.

## What This Is

This repo is just a table. Each row links to a GitHub profile and to the
raw README file that powers it, so you can see both the live result and
the markdown/HTML behind it. No profile is too simple or too fancy to be
listed, what matters is that it's genuinely yours and it's put together
with some care.

## How to Add Yours

1. Fork this repository
2. Add a new row to the table above with:
   - Your name (or however you'd like to be listed)
   - A link to your GitHub profile
   - A link to your profile README's source file
3. Keep the table sorted alphabetically by first name
4. Open a Pull Request

Full details are in [CONTRIBUTING.md](CONTRIBUTING.md).

## Contributing Guidelines

- One entry per person
- The profile README must be your own, publicly visible work
- Keep the PR focused: just your table row, no unrelated changes
- Be respectful, no offensive usernames, content, or links

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full guide.
